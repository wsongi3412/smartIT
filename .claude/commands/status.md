description: ExamSentry 진행 상황을 쉬운 말로 요약
---
ExamSentry 프로젝트의 지금 상황을 팀원에게 설명해 줘.

1. `git pull` 로 최신 상태를 받고, `CLAUDE.md`, `docs/진행기록.md`, `git log --oneline -10` 을 읽어.
2. 아래 순서로 한국어로 짧게 정리해:
   - 최근에 바뀐 것 (최근 커밋과 진행 기록 기준, 날짜 포함)
   - 지금 상태: "가짜 데이터로 돌려 봄" / "컴파일만" / "ESP32 와야 확인" / "아직 없음" 을 구분해서
   - 다음에 할 일 (진행 기록의 "다음에 할 일"), 가장 급한 것 먼저
3. 시뮬레이션 숫자를 실제 성능처럼 말하지 마.
