description: 감독관 태블릿 화면을 가짜 데이터로 띄워 보기
---
ExamSentry 대시보드를 가짜 데이터로 띄워서 보여 줘.

1. `pip install -r requirements.txt` 가 안 되어 있으면 설치해.
2. `python server.py` 를 백그라운드로 실행하고, 브라우저에서 http://localhost:8000 을 열라고 안내해.
3. 화면에서 무엇을 보면 되는지 설명해 줘: 교실 배치도 색, 신호 목록의 관찰→높음 변화, 50분 뒤 "쉬는 시간 · 확인할 곳" 배너, 센서 4대 상태.
4. 끝나면 서버를 멈추는 방법도 알려 줘.
