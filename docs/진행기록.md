  - 보정(신호 지도 보충)은 [설정] → [보정] 창으로 옮김 (실시간·시험 전에만)

  - 확인: `python server.py --at 60`(서버 가짜 재생) 화면, `fake_live.py` + `server.py --live --scale 40` 으로 대기→기준 측정→시험(45분 선택)→45분에 자동 쉬는 시간까지 화면 캡처로 확인. 실제 센서로는 아직
- **ESP32 5대 모두 새 펌웨어** (채널 자동 맞춤 + LED). 1대 추가로 와서 수신기로 씀

  | 보드 | 역할 | MAC |
  |---|---|---|
  | 새 보드 | 수신기 | a0:a3:b3:2c:02:8c |
  | 1번 | 센서 A | b0:b2:1c:97:0a:cc |
  | 3번 | 센서 B | e4:65:b8:74:c7:28 |
  | 새 보드 | 센서 C | 68:fe:71:0c:f8:88 (LED 확인) |
  | 예비 1 | 센서 C 펌웨어 | 08:d1:f9:eb:06:08 — 다른 프로젝트 보드였음(원래 프로그램 지움). GPIO2 파란 LED 없음 |
  | 예비 2 (예전 C) | — | e8:6b:ea:c9:dc:dc — USB가 노트북에 안 잡힘. 11-25 펌웨어(LED 없음) |
  | 2번 (예전 수신기) | 센서 D | 68:fe:71:0c:ec:c4 |

  - 각 보드 USB로 확인: 센서 ready 줄 + 10~15초에 BLE·Wi-Fi 데이터 줄 80~120개
  - 센서는 BLE+Wi-Fi라 커서 **PartitionScheme=huge_app** 로 컴파일해야 함 (기본 설정이면 "text section exceeds available space")
  - 아이폰 핫스팟은 연결된 기기가 없으면 잠시 뒤 숨음 → 센서 켤 때 **개인용 핫스팟 설정 화면을 열어 두거나 태블릿을 먼저 연결**. 못 찾으면 6번(기본값)으로 감
  - **LED 실기 확인** (센서 A·C): 핫스팟 5GHz일 때 3번 깜빡임 → 호환성 최대화 켜고 다시 켜니 `found on ch 6` + 파란 LED 1번씩 깜빡임
  - **센서 4대 동시 무선 확인** (채널 돌기 펌웨어, 보조배터리·충전기, 수신기만 노트북): `# 10s A:17 B:20 C:26 D:27 lost A:1` → `A:19 B:17 C:24 D:23 lost 0`. 35초에 데이터 줄 A 802 · B 857 · C 1257 · D 1250. 빠짐 약 1% (A 1개). 센서는 충전 전용 케이블로도 됨
- **에어팟 첫 실측** (센서 C 1대, USB, 사람 많은 곳·주변 BLE 120~180개): 노트북·휴대폰 블루투스를 하나씩 끄고 켜며 30초씩 비교
  - 에어팟 귀에 꽂고 음악 재생 중: 주소 1개(`52:82:a7…`)가 **30초에 14~15번**, -49~-54dBm → 케이스에 넣고 닫으니 사라짐 → 에어팟으로 판단 (1회 비교, 다시 확인 필요)
  - 휴대폰(`49:92:7d…`)은 에어팟과 상관없이 계속 잡힘 (-27~-31dBm)
  - 뜻: 연결·재생 중인 에어팟도 BLE 알림 신호를 계속 냄 → 50분이면 충분히 쌓임. 다른 기기(버즈, 휴대폰 화면 꺼짐, AI 안경)는 아직
  - 와이파이는 핫스팟 채널(6번)만 들음 → 다른 채널 기기를 놓침 → **센서 펌웨어에 채널 돌기 추가** (`WIFI_HOP 1`: Wi-Fi 1초 동안 핫스팟 채널 + 1·6·11번을 333ms씩, 보내기 전에 핫스팟 채널로 복귀, `MAXE` 48→96)
    - 센서 C 실기: 30초에 잡힌 Wi-Fi 기기 68개(6번만) → **115개**(6·1·11번). CAM(6번)은 30초 6줄 → 약 4.5줄 (듣는 시간이 1/3이라 줄었지만 계속 잡힘)
    - 5GHz는 ESP32로 못 들음 → 발표 때 한계로 밝히기 (다음 단계: 5GHz 되는 칩)
    - **센서 A·B·C·D 모두 올림** (각각 USB로 `wifi listen channels: 6 1 11` + 데이터 줄 확인). 수신기는 그대로
- 알루미늄 테이프는 **교실↔복도 오른쪽 벽 한 면만** (높이 ~20cm, 틈 없이 겹쳐 붙이기, B·D 기둥과 3cm 이상). 나머지 면·기둥·바닥은 금속 금지
