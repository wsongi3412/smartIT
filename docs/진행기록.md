## 2026-11-18

- 코드 기준을 GitHub(`smartIT`)로 정함. 코드 수정은 송이가 하고 push
- 가짜 센서 데이터로 전체 흐름 완성: 수집 → 위치 판정 → 의심도 → 태블릿 대시보드
- 시뮬레이션으로 정한 것
  - **알루미늄 테이프 벽 필수**: 우드락만이면 복도→교실 오판 40%, 테이프 8%
  - 판정에 "가장 센 값"도 넣어야 벽 정보가 살아남음
  - BLE는 신호가 드물어서 누적 시간 = 잡힌 시간 × 교실 안 비율
  - MAC이 바뀌는 기기는 신호 세기 지문이 비슷하면 이어 붙임 (AI 안경 10/10)
  - **센서 4대**: 3대보다 정확하고, 1대 고장 나도 남은 센서로 판정 유지 (고친 뒤 76%)
- 실시간 모드 리허설: `--scale 40` 이면 2분 시연 대본과 맞음, 50분 되면 자동 쉬는 시간
- 이어폰 대역은 팀원 **에어팟·버즈** 사용 (안 잡히면 BLE 비콘으로 대체)
- 감지 대상 정리: 초소형 이어폰(귀 속)·어금니 골전도는 이어폰 자체가 아니라 **블루투스 중계기**를 잡음 → "부분" 감지. 유심(LTE) 중계기는 못 잡음
- 소개서 v3 작성 (`docs/ExamSentry_소개서_v3.pdf`), 예산 추정 약 9만~16만 원
