# 2. 신호 지도 측정 절차서 (동현 · 초안, 1쪽)

> 목적: 자리마다 기기를 두고 센서 4대가 받은 세기를 기록 → AI(k-NN)의 정답 데이터.
> 1일차 = 학습용, **다른 날** 2일차 = 검증용. 두 날 모두 이 절차 그대로.

## 준비 (10분)
1. 모형에 센서 A~D 꽂고 USB 허브로 노트북 연결. 알루미늄 테이프 벽 확인.
2. 측정 자리 평면도(`1_측정자리_평면도.md`)를 출력해 모형 옆에 두기. 자리마다 스티커 번호.
3. 비콘(여분 ESP32) 주소와 ESP32-CAM 주소를 시리얼 모니터에서 확인해 적어 두기.
4. 주변 휴대폰 블루투스·Wi-Fi 끄기 (측정하는 사람 포함).

## 측정 (기기 1개당)
**터미널 1** — 센서 기록 (끝날 때까지 켜 둠)
```
python serial_reader.py data/calib_day1.csv
```
**터미널 2** — 자리 라벨 기록
```
python stage_log.py data/calib_day1.csv --id <비콘 주소>
```
자리마다 반복:
1. 기기를 그 자리에 놓고 **손을 뗀다** (몸이 신호를 가림)
2. 구역 번호 입력 → Enter = 시작 (1 앞왼쪽 · 2 앞오른쪽 · 3 뒤왼쪽 · 4 뒤오른쪽 · 5 가운데 · 6 복도)
3. **30초** 기다림 → Enter = 끝 (코드 최소 권장은 6초, 계획 기준은 2초 샘플 15개 이상 = 30초)
4. 기록지에 `자리 번호 / 끝난 시각` 적기 → 다음 자리

순서: 1-1 → 1-5, 2-1 → … → 5-5 (25자리), 그다음 H1→H4. **총 29곳.** 구역 번호는 평면도의 구역 표 (3줄·3열은 5 가운데).

## 반복 조합 (총 4바퀴)
| 바퀴 | 기기 | 사람 | --id |
|---|---|---|---|
| ① | 비콘 | 없음 (모형에서 1m 떨어짐) | 비콘 주소 |
| ② | 비콘 | 있음 (모형 옆에 2명 앉기) | 비콘 주소 |
| ③ | ESP32-CAM | 없음 | CAM 주소 |
| ④ | ESP32-CAM | 있음 | CAM 주소 |

기기가 바뀌면 터미널 2를 `q`로 끄고 `--id`를 바꿔 다시 켠다 (같은 라벨 파일에 이어서 쌓임).
예상 시간: 29곳 × 30초 × 4바퀴 ≈ 58분 + 옮기는 시간 → **약 1시간 30분**.

## 끝나고
- 결과: `data/calib_day1.csv`(신호) + `data/calib_day1_labels.csv`(자리 라벨). 팀 드라이브에 백업.
- 모형 사진 1장 (센서·자리 스티커 보이게).
- 2일차는 파일 이름만 `calib_day2` 로.
- 채점: `python evaluate.py --calib-train data/calib_day1.csv --calib-test data/calib_day2.csv`
