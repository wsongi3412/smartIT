# 1. 측정 자리 평면도 (동현 · 초안, 11-24 5×5 자리로 수정)

기준: `config.py` (11-24) — 모형 900×600mm, **칠판이 앞(y=0), 복도는 오른쪽 벽 바깥 (x 900~1050)**.
수능 시험실처럼 **5×5 = 25자리**. 자리 이름은 **`줄-열`** (1줄 = 칠판 쪽, 5열 = 복도 쪽). 예: `4-5` = 4줄 5열.
한 자리 칸 = 가로 180 × 세로 120mm. 책상 가운데 좌표 = ((열−0.5)×180, (줄−0.5)×120).

```
                         앞 (칠판)
   A ───────────────────────────────────────────── B ┬───────┐
   │  1-1     1-2    [1-3]     1-4     1-5         ║  H1   │
   │                                               ║       │
   │  2-1    *2-2*   [2-3]    *2-4*    2-5         ║  H2   │
   │                                               ║       │
   │ [3-1]   [3-2]  *[3-3]*   [3-4]   [3-5]        ║  H3   │
   │                                               ║       │
   │  4-1    *4-2*   [4-3]    *4-4*    4-5         ║  H4   │
   │                                               ║       │
   │  5-1     5-2    [5-3]     5-4     5-5         ║       │
   C ───────────────────────────────────────────── D ┴───────┘
   [ ] = 가운데 구역 (3줄 전체 + 3열 전체, 9자리)    ║ = 알루미늄 테이프 벽
   * * = 대표 자리 (대회장 보정 때 다시 잼)          5열(1-5 ~ 5-5) = 복도 쪽 벽 앞
```

## 구역 (`config.seat_zone`, stage_log 번호)

| 구역 (번호) | 자리 | 대표 |
|---|---|---|
| 앞왼쪽 (1) | 1-1 1-2 2-1 2-2 | 2-2 |
| 앞오른쪽 (2) | 1-4 1-5 2-4 2-5 | 2-4 |
| 뒤왼쪽 (3) | 4-1 4-2 5-1 5-2 | 4-2 |
| 뒤오른쪽 (4) | 4-4 4-5 5-4 5-5 | 4-4 |
| 가운데 (5) | 3-1 3-2 3-3 3-4 3-5 · 1-3 2-3 4-3 5-3 | 3-3 |
| 복도 (6) | H1 (975,60) · H2 (975,220) · H3 (975,380) · H4 (975,540) | H2 |

- 측정은 **25자리 전부 + 복도 4곳 = 29곳**. 자리마다 책상 가운데에 기기를 둔다.
- 가운데 구역이 십자 모양인 이유: 3줄·3열은 양쪽 센서와 거리가 같아 왼쪽/오른쪽(앞/뒤)이 원래 헷갈리는 자리라 따로 묶었다.
- 1일차·2일차 모두 **같은 자리**로 잰다 (학습/검증 분리).
- 시험 연출 정답(`note`)에도 `자리4-5` 처럼 줄-열로 적는다.

## 모형 담당(지은)에게
- 책상 25개를 5×5로 (칸 180×120mm, 책상은 칸 안 가운데). 자리마다 `줄-열` 스티커.
- 3줄·3열 책상은 색 테이프로 표시하면 가운데 구역이 한눈에 보임.
