# 1. 측정 자리 평면도 (동현 · 초안)

기준: `config.py` (11-23) — 모형 900×600mm, **칠판이 앞(y=0), 복도는 오른쪽 벽 바깥 (x 900~1050)**.
좌표 단위 mm, A 모서리 = (0, 0). x는 오른쪽, y는 뒤쪽으로 커짐. 센서 B·D가 복도 쪽 벽.

```
                         앞 (칠판)
   A ─────────────────────────┬──────────────────────────── B ┬───────┐
   │  1                  2    │   6                   7      ║  H1   │
   │                          │                              ║       │
   │          3               │          8                   ║       │
   │                          │                              ║  H2   │
   │  4                  5    │   9                  10      ║       │
   ├────────────────────────[21]─────────────────────────────║       │
   │ 11                 12    │  16                  17      ║  H3   │
   │                          │                              ║       │
   │         13               │         18                   ║       │
   │                          │                              ║  H4   │
   │ 14                 15    │  19                  20      ║       │
   C ─────────────────────────┴──────────────────────────── D ┴───────┘
                                                             ║ = 알루미늄 테이프 벽
                                       7·10·17·20 = 복도 쪽 벽 앞 (복도와 헷갈리기 쉬움)
```
